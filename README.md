# tictactoe-minimax-ai

# Unbeatable Tic Tac Toe 🧠❌⭕️

A simple yet smart **Tic Tac Toe** game built with **HTML, CSS, and JavaScript**.  
It features a clean aesthetic UI and an **unbeatable AI opponent** powered by the **Minimax algorithm**.

## 💡 Features
- 🎮 Play as Player X against AI O
- 🧠 Smart AI using Minimax (never loses!)
- ✨ Aesthetic responsive UI with soft colors
- 🔁 Restart functionality
- ⚡ Lightweight and fast – no dependencies

## 🚀 How to Run
1. Clone this repository  
2. Open `index.html` in any browser  
3. Start playing!

🧠 About the AI
The computer uses the Minimax algorithm, which ensures:

It never loses
It chooses the optimal move every turn
At worst, the game ends in a draw
